Installation :
1. Apparence > Themes > Ajouter un theme > Televerser un theme
2. Importer ce ZIP
3. Activer le theme
4. Definir une page comme page d accueil
5. Ajouter votre logo blanc transparent dans Apparence > Personnaliser > Identite du site
6. Ajuster telephone, adresse et CTA dans Apparence > Personnaliser > ECO Electricite - Infos entreprise
